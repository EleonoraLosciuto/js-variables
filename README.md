# JS VARIABLES

This project is the tenth exercise of the Web Development Master Course, marking the first hands-on application of JavaScript. The focus is on understanding how to declare, manipulate, and operate on different types of variables.

## TASK

The primary goal was to complete a series of logic and math challenges within three structured folders:
- **Numbers**: Performing arithmetic operations
- **Stings**: Working with text data, in particular concatenation
- **Strings Bonus**: Implementing advanced string methods to transform data, such as replace, substring and split

## PROJECT STRUCTURE

```text
js-variables/
├── 01-numbers/
│   ├── index.html          # html Number exercises
│   └── script.js           # JavaScript logic for numerical operations, including challenges to be performed
├── 02-strings/
│   ├── index.html          # html String exercises
│   └── script.js           # JavaScript logic for text manipulation, including challenges to be performed
├── 03-strings-bonus/
│   ├── index.html          # html Advanced String exercises
│   └── script.js           # JavaScript logic for advanced methods (split, replace, etc.), including challenges to be performed
└── README.md               # Project Documentation
```
